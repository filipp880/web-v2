# Автономные геоданные

`moscow.geojson` — локальная подложка района Москвы, подготовленная из данных © OpenStreetMap contributors, лицензия [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Атрибуция отображается на карте. Данные получены 12 октября 2026 года через [OSM API](https://api.openstreetmap.org/api/0.6/map?bbox=37.635,55.757,37.65,55.77).

Геометрия демонстрационного пути `moscow-tram.json` в Infrastructure подготовлена из того же источника: 54 вершины, около 1158 м по существующим трамвайным рельсам. Демопрогоны показывают движение по этому участку или обратно; это демонстрационные сценарии, а не официальные маршруты перевозчика.

Для воспроизводимости скачайте XML по ссылке выше в `TramWebApp/tram-area.osm`, затем из `TramWebApp` выполните `python scripts/build-map-assets.py`. Генератор обновляет оба файла. Для обычного запуска Python и загрузка данных не нужны.

Дополнительно поддерживается `VITE_2GIS_API_KEY` при сборке frontend. По умолчанию ключ отсутствует, внешние тайлы не запрашиваются. При недоступности 2ГИС используется локальная подложка.
