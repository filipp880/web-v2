# TramWebApp

Учебное приложение для мониторинга трамвайных прогонов, просмотра телеметрии и управления движением в тренажёре. ASP.NET Core API, React-клиент, PostgreSQL и отдельный режим хранения в памяти для лабораторной работы 2.

## Быстрый запуск

Нужен запущенный Docker Desktop с Linux-контейнерами.

```powershell
git clone https://github.com/filipp880/web-v2.git
cd web-v2/TramWebApp
docker compose up --build -d
```

- Приложение: http://localhost
- Swagger: http://localhost/swagger/index.html
- Вход администратора: `admin` / `admin123`
- Вход пользователя: `operator` / `user123`

Для знакомства выберите демонстрационный прогон под администратором. Можно открыть телеметрию, воспроизведение и графики либо нажать **«Управлять трамваем»** для создания отдельного прогона тренажёра с записью данных на сервере.

Модель оценки скорости демонстрационная. Тренажёр использует учебную динамику с инерцией и зимним сцеплением. Схема маршрута и локальная карта запускаются без API-ключа.

Для отдельного режима ЛР2 без PostgreSQL, из каталога `TramWebApp`:

```powershell
docker compose -p tramwebapp-lab2 -f docker-compose.lab2.yml up --build -d
```

Клиент ЛР2: http://localhost:8082. В этом режиме хранится до 50 прогонов, данные исчезают после перезапуска API. Основной запуск с PostgreSQL сохраняет данные в Docker volume.
